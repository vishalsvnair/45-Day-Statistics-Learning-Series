## ⚠️ Important Statistical Concepts

This series emphasizes several concepts that Data Analysts frequently
misunderstand:

> **Correlation ≠ Causation**

> **p-value ≠ Probability that the null hypothesis is true**

> **Statistical significance ≠ Business significance**

> **Sample ≠ Population**

> **Standard deviation ≠ Standard error**

> **Confidence interval ≠ Prediction interval**

> **Outlier ≠ Automatically bad data**

Understanding these distinctions is just as important as memorizing
formulas.

## 📊 Example

### Standard Deviation

Suppose daily sales are:

``` text
100, 120, 80
```

Mean:

``` text
(100 + 120 + 80) / 3 = 100
```

Population variance:

``` text
[(100-100)² + (120-100)² + (80-100)²] / 3
= 800 / 3
≈ 266.67
```

Population standard deviation:

``` text
√266.67 ≈ 16.33
```

This tells us that daily sales typically vary around the mean of **100**
by about **16.33 units**, under the population definition.

## 🌟 Why Statistics Matters for Data Analysts

A Data Analyst doesn't just answer:

> "What happened?"

Strong analytics also asks:

> "How reliable is this result?"

> "Could this difference happen by chance?"

> "How much variability exists?"

> "Is the relationship meaningful?"

> "Can we generalize this result?"

> "What decision should the business make?"

Statistics provides the foundation for answering these questions.
